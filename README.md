# flag-coloring-game

子ども向けの国旗いろぬりブラウザゲームです。

## コンセプト

- おてほんの国旗を見ながら、線画の国旗を正しい色で塗る
- 色はドラッグ&ドロップ、またはタップで選択して塗る
- 正解色に似せた誤答色もカラーパレットに混ぜる
- 正解すると祝福エフェクト後に次の問題へ進む
- 「おわる」で正解した国旗数を表示し、正解済み国旗を万国旗風に並べる
- 難易度の高い国旗はゲーム後半で出題する

## 現在の実装

初期MVPとして以下を実装済みです。

- PC / タブレット / スマホ向けレスポンシブUI
- SVGベースの塗り領域
- ドラッグ&ドロップ操作
- タップ / クリック操作
- 正誤判定
- 紙吹雪エフェクト
- 3秒後の自動次問遷移
- 終了画面 / 再スタート
- 初期国旗5か国（日本、ウクライナ、フランス、ドイツ、イタリア）
- 基礎的な段階出題
